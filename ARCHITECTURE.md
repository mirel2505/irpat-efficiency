# Architecture — irPaT & Eficiență
Proposed architecture; interfaces are not yet stable. See SPECIFICATION.md.

- Python HA integration under custom_components/irpat_efficiency; domain irpat_efficiency. Local config entry lifecycle, stable per-installation identifiers, runtime data scoped by config entry; unsubscribe listeners on unload. No equipment service calls.
- Config flow creates an empty user-named installation; options/reconfigure and dedicated editor manage floors, hydraulic zones, sources, manifolds, circuits, rooms, sensor aliases and bindings. Separate identity from display name; sensor replacement changes binding, not historical room identity. Floor is physical; zone is hydraulic; do not assume one-to-one.
- Pure Python calculations with explicit units, Optional values, provenance, time coverage, mode and eligibility; independent of HA for tests. Input adapters normalize temperature, flow, power, energy and source status; no silent assumptions or fabricated zero. Time-aware collection/aggregation and bounded queues; no synchronous I/O on event loop.
- Storage versioned and partitioned: config entry data, HA Store for modest configuration/journal/profile data, bounded aggregates (storage engine to benchmark), optional Recorder adapter. Atomic writes, migration tests, restore validation and no raw-history duplication. UTC storage, local-time presentation; timezone/DST tests.
- Analysis modules: capabilities, validation, thermal_balance, hydraulic_balance, climate_curve, thermal_analysis, efficiency, cooling, recommendations, history. Evidence and uncertainty attached to results. Independent modules degrade gracefully; no automated control.
- WebSocket API for authenticated panel reads and authorized configuration writes, with schema validation and admin authorization for mutation. No arbitrary service calls, no dynamic code, no external network dependency; diagnostics redact identifiers, addresses and personal labels by default.
- TypeScript + Lit frontend, compiled assets shipped with integration; native HA theme, keyboard/touch navigation, accessibility, ro/en translations, simple/expert modes, graphical wizard, interactive manifolds and floor plan. Dedicated panel registration/unload and static asset loading require integration tests before release.
- HACS custom repository first; public release and default catalog application only after validation. GPL v3 license maintained. README + .github/FUNDING.yml voluntary support.
